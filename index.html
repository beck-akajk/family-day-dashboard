    폰에서 체크하고 태블릿에서도 같은 화면으로 — 설정·루틴·스티커·주간 숙제가 함께 맞춰져요.

    이 기기에만 저장하고 있어요.

    구글 시트 · Firebase 연결 방법
    1. 구글 시트: 우리 집 하루 - 동기화 데이터 → 확장 프로그램 → Apps Script 에 google_apps_script_sync.gs 내용을 붙여넣고 저장해요.
    2. 오른쪽 위 배포 → 새 배포 → 웹 앱 (실행: 나 / 액세스: 모든 사용자) 으로 배포하고, 나오는 /exec 주소를 위 칸에 붙여넣어요.
    3. Firebase: Realtime Database를 만든 뒤 데이터 탭 주소 끝에 /family_day.json을 붙여 넣어요. (보안 규칙에서 읽기·쓰기를 허용해야 해요)
    4. 연결한 뒤 공유 링크 복사를 눌러 다른 기기로 보내면, 그 기기는 입력 없이 바로 연결돼요. 링크에 동기화 주소가 들어 있으니 가족끼리만 보내 주세요.
