# 그림자 성채 · SHADOW CRYPT

모바일 가로 양손 조작 + PC 키보드/마우스로 즐기는 다크 판타지 핵앤슬래시 RPG.
외부 이미지·음원 없이 캔버스 2D와 Web Audio 합성음만으로 만들어졌습니다.

- 플레이: https://beck-akajk.github.io/family-day-dashboard/shadow-crypt/
- 구성: `index.html` (화면·HUD·CSS), `game.js` (엔진·전투·아이템·저장)

## 조작
| | 모바일 | PC |
|---|---|---|
| 이동 | 왼쪽 화면 아무 곳이나 터치(그 자리에 조이스틱) | WASD / 방향키 |
| 공격 | 오른쪽 큰 붉은 버튼(길게 누르면 연타) | J / Space / 마우스 왼쪽 |
| 스킬 | 오른쪽 위 3개 버튼 | 1 2 3 (또는 U I O) |
| 대시 | 💨 버튼 | Shift |
| 물약 | 🧪 버튼 | Q |
| 가방 | 가방 버튼 | E / Tab |
| 일시정지 | ☰ 버튼 | Esc |

## 클래스
- 야만용사: 회전베기 · 도약 강타 · 전투 함성
- 원소술사: 화염구 · 빙결 파동 · 유성 낙하
- 악마사냥꾼: 연발 사격 · 관통 화살 · 연막 도약

## 진행
보스를 쓰러뜨리면 균열이 열리고 다음 층으로 내려갑니다. 층이 깊을수록 적과 장비 등급이 올라갑니다.
장비는 일반(흰) / 마법(파랑) / 희귀(노랑) / 전설(주황, 고유 효과) 4등급이며, 가방에서 장착·분해·강화할 수 있습니다.
진행 상황은 브라우저 localStorage에 자동 저장되어 이어하기로 복귀합니다.
